WebSSH shortcuts

      

      
    

    

      

        
Desktop

        
Ctrl/Cmd + F opens terminal search. Ctrl/Cmd + Shift + F toggles fullscreen.

        
Ctrl + C and Ctrl + D are sent directly to the remote PTY.

        
Escape, arrows, Tab and common shell keys are available in the mobile key bar.

      

      

        
Security

        
Never put a real password in a URL. Use HTTPS and a protected backend when exposing WebSSH publicly.
